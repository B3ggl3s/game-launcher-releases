# Game Launcher — releases

This repository holds **installers only**: no source code.

**Download the latest version:** https://github.com/B3ggl3s/game-launcher-releases/releases/latest  
Get `GameLauncher-Setup-X.Y.Z.exe` and run it. Windows SmartScreen may warn because the installer isn't code-signed; click **More info → Run anyway**.

Once installed, Game Launcher updates itself automatically from the releases published here.
